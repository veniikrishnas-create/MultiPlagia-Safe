🛠️ Help & Support

PlagiaSafe supports multiple types of content: text, slides, paraphrase, code, image, and resume scanning. Follow this guide to use each feature efficiently.

1. 📄 Text Scanning

  • 📝 Upload .txt, .docx, .pdf files
  • 🔍 Highlight similar content and check similarity percentage
  • 📥 Download detailed report

2. 📊 Slide Scanning

  • 🖼️ Upload .pptx or .pdf slides
  • 🔍 Check each slide for similarity
  • 📥 Download slide-based plagiarism report

3. ✍️ Paraphrase Detection

  • 🔄 Highlight paraphrased text
  • 📊 Shows similarity score even for reworded sentences
  • 📝 Works with text and document uploads

4. 💻 Code Scanning

  • 🐍 Python, ☕ Java, C, C++, JS supported
  • 🔍 Detects exact matches, structure similarity, and logic reuse
  • 📄 Detailed code comparison report with highlighted sections

5. 🖼️ Image Scanning

  • 🖼️ Supported formats: .jpg, .png, .jpeg
  • 🔍 Highlight similar images from database
  • 📥 Download image similarity report

6. 📑 Resume Scanning

  • 📄 Supported formats: .pdf, .docx
  • 🔍 Check similarity with existing resumes or sample templates
  • 📊 Get detailed similarity percentage and highlighted sections

7. ❓ FAQs & Troubleshooting

  • 🗂️ Q: Can I scan multiple files at once?
    A: Yes, batch uploads are supported.
  • 📦 Q: What file size is allowed?
    A: Max 10MB per file recommended.
  • 🔒 Q: Is my data safe?
    A: Yes, all files are encrypted and deleted after processing if configured.
  • 🖥️ Q: Video or styles not loading?
    A: Clear browser cache and refresh the page.
